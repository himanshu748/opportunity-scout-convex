## First maker comment

I wanted one place to find active hackathons and see how much of a prize pool is actually cash. I built Scout to make choosing one easier.

Scout checks event sources daily, keeps application deadlines beside the original brief, and separates confirmed cash from other rewards. You can save opportunities and ask for a shortlist based on your skills, location and available time. Weekly email is optional.

I built it with GPT-6 Astra in Codex. The work included the React interface, Convex authentication and scheduling, source validation, and testing the live app. The advisor inside Scout uses OpenAI GPT-4.1 mini through Mastra and Convex AI Gateway.

Discovery is still growing. If Scout misses an event, you can submit its official link for verification. I'd love feedback on which sources and filters would make this useful for your next build.
